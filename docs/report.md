## 研究标签层级与试听

大类为 NVV 非言语人声、说话人线索、说话方式 / 语言、背景音 / 声音事件、音乐 / 歌唱、其他 / 待核验，下设 25 个小类。原始描述保留不变；按版本化规则允许多类命中，因此不同类数量不能直接相加。疑似人名但无明确依据的描述保留在待核验类，不能当作全局 speaker ID。规则与完整映射可在页面导出。

提取 138 段真实 PCM WAV 试听，覆盖 23 个小类，同一小类尽量来自不同作品与批次。片段按实际配对字幕中的精确标签定位，优先选择只有声音描述、长度 0.7–7 秒的条目，前留 0.3 秒、后留 0.4 秒；没有做降噪、增益归一化或生成音频。字幕语义与声音是否对应、事件纯度和前景背景位置尚未人工听审。此少量参考库不是随机抽样，不能用于推断全库事件分布；没有试听的小类不代表没有对应数据。每段可导出原文件路径、字幕、起止时间和 SHA-256。
