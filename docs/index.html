    01 / 数据实际提供了什么

    音频与字幕：文件级 ID、片名（有 meta 时）、作品 ID、季 / 集、音频时长、采样率、声道、位深、字幕文本和起止时间。

    声音描述：SRT 方括号原文、歌词符号、人物 / 说话人线索。可用于查找笑声、哭泣、呼吸、音乐和不同说话方式。

    源元数据：逐个作品读取完整 meta.json 并核验作品 ID，按季 / 集匹配剧集名称、年份与 runtime。没有来源、解析失败和字段本身缺失分别记录；片名语言不代表音频语言。

    模型评估：全量读取已有 CSV 与逐段 JSONL，保留来源和有效覆盖数。文件 WER 是有效分段均值；全局按词加权 WER 单独展示。

    02 / 适合从这里开始的任务

    ASR 语料预筛：使用配对与时间检查剔除明显问题，再用已有 WER 作为辅助信号。低 WER 文件仍需抽听。

    副语言与声音事件：用描述类别定位候选作品，再按 SRT 时间切片。人物、事件和语气可能出现在同一个方括号中。

    多语言 / 配音研究：源目录中观察到多语言 VTT 和媒体文件。同批次跨目录的同名文件可作为配音/双语候选，仍需验证实际语言和时间对齐。wavs_zh 是目录名称；应检查音轨及字幕语言后再当作中文语料。

    TTS 准备：先做语音活动检测、说话人分离、字幕强制对齐与音质筛选。整片音频通常含背景音乐、多人对话和音效。

    03 / 推荐准备流程

    1文件与字幕配对从页面导出 SCP / CSV
    2按字幕切分候选片段保留原始描述与时间戳
    3对齐、分离、抽听确认说话人和背景干扰
    4按作品划分数据集同作品及同剧集避免跨集泄漏

    04 / 统计口径与复现

    范围：/home/work_nfs27/tts_data/Netflix/netflix_data*/wavs 及同级 wavs_zh。主目录与补充目录分开统计，合计不代表内容去重后的规模。

    标签统计：读取已分析文件的全部 SRT 条目（实际覆盖见页面顶部）；提取方括号中的描述，将大小写和空白归一化。类别是启发式规则，非官方标注。每个文件详情仅展示最频繁的 12 个标签，完整语料标签字典可导出。

    WER：精确匹配 JSONL 的 wav_path，按有效分段计算文件均值；CSV 仅补充可唯一定位且 num_parts=1 的文件。未匹配评估、无可评分语音和记录冲突分开计数。不把主目录分数转移到另一音轨。低 WER 不能直接证明 TTS 音质好。

    时间检查：字幕重叠、无效时间、超出音频长度均为待复核信号；字幕时长求和未去重，不表示实际语音时长。

    重复检查：仅比较主目录文件 ID，没有读取音频内容做哈希；跨目录相同 ID 也不代表音轨完全相同。

    后续更新：在本项目运行 python analysis/update_snapshot.py，刷新统计快照。SSH 沿用本机配置，扫描只读。断点按文件路径复用；如果服务器原文件更新，请另存旧断点后重新扫描。文件头检查范围见数据规格；未检查部分不当作读取成功或读取失败。
